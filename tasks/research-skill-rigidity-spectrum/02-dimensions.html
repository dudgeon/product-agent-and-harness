Skills on the spectrum

A skill is a score, not a dial. Seven dimensions set how a skill or agent encodes a piece of product work, and each is set per step, not once for the whole skill. Click a stop on each dimension to place a skill, or load a preset. Techniques and sources appear under the stop you pick.

From the research synthesis of 2026-10-25 (research-skill-rigidity-spectrum). Evidence labels: first-party, vendor claim, independent, anecdote. Source slugs name notes in the project's research library.

Two modifiers that are not dimensions of the skill

Party count. A long-running session with several people and agents adds no techniques; it raises the weight of Check and Record. The failure modes it adds: claimed-but-not-done work (agent task status lags; checklists "documented as complete"), clarification never asked, records drifting as contributors rotate. Claude Code agent teams (first-party); MAST, Urbach (independent).

Competence fit. Whether the step sits inside the model's competence, and whether the person alone beats the model alone, decides the right stance and rights for that step. It moves with every model release. BCG consultants; Vaccaro meta-analysis (independent).
