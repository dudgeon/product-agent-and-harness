Where Uber’s agents sit in the product lifecycle, task by task

Anchored on tasks, not job titles: Uber’s assistant Cortana is for “anyone in the company”, and PMs, designers and engineers each also have their own tools. Each handoff is marked documented, inferred or unknown. Every figure is Uber’s own.

Uber documents the shaping-to-code handoff, but not how it works

  1. One assistant covers research → requirements → mock-ups → plan. In the August 2026 demo, a Slack thread tags Cortana. Cortana judges the business opportunity from the context graph, drafts requirements, makes Figma mock-ups for an A/B test and lists the code to reuse. Then “we hand off from that Cortana agent” to Minion, the cloud coding agent. Stripe’s record has no such link.
  2. What crosses is not shown. The nearest documented mechanism is “@minion, follow this thread … create a PR”. Minion also takes a plan or a “really good spec”.
  3. Specs have a tracked home that agents read, but Cortana’s link to it is unknown. uPlan holds PRDs, ERDs, launch, experiment and readiness reviews with Jira or Linear links, all fed into the context graph: “a source of truth system for both humans and agents to know the specs for every project”. Whether Cortana’s drafts land there, or pass the PRD Evaluator, is not stated.

What the task view adds: at Uber the shaping tasks sit in one shared assistant, often in a team’s Slack channel, so context can travel in Cortana’s thread rather than in someone’s head. The open seam is the artifact. Does shaped intent become a reviewed, tracked spec before code, or go straight from a chat to a PR?

What it means for our options

  • One shared assistant across the shaping tasks is a running option. Uber uses one company assistant with team personas; Stripe splits the same tasks across Kai, Harbor and Orbit.
  • Specs as a graph that agents read. uPlan’s PRDs, ERDs, reviews and ticket links feed the context graph, so the spec is a tracked record, not a file in one repo.
  • The spec gate before code is still the open seam. Cortana’s drafts, the PRD Evaluator, uPlan and Minion all exist, but no source joins them.
  • Feature velocity needed rebuilt links. Uber used AI to back-fill PRD → ERD → task links before it could measure P50 feature time: evidence for a dependency agent that writes links back.
