## Request

New worker task: I need to create a research-grounded taxonomy of agent runtime patterns that apply for coding and knowledge work task. Today, most of our target users work directly with Claude code, a general purpose agent harness. These harnesses can be augmented with skills and subagents. But I'm curious about other patterns to make the work of a user less dependent on a specific harness, introduce the ability to have standardized sub-agents or skills that embody more complexity and advanced features. We also seek to move session from being local, private, and ephemeral — to deployed, shareable/multi-human-user, and persistent. Agent frameworks allow us to build our own harness to replace Claude code (not sure we want to go this route), but I think other patterns must exist — eg "meta harnesses" if this is the correct term, like Ormnigent and a new offering from cloudflare (research others); or perhaps the ability for Claude code or codex to also leverage powerful deployed agents, that encode task specific logic and capabilities, but whose runtime is outside of the 'primary' harness. I think there are a couple classes of user activity (you will do research to learn more): the general purpose planning and ideation work that is and wants to remain unstructured (and needs a powerful, flexible harness), and the more task-specific work (like standardizing how we do PRD review) that wants to live in a task-specific agent. This is a very broad research topic. Opus should define a research plan, spin up multiple research sub agents, and then fable should coalesce the findings, including an executive summary and map of the identified themes, concepts, and patterns; as the research raises questions I am standing by to provide direction.

Not for the worker to decide alone: whether to build our own harness (Geoff is unsure; research the option, don't recommend it as settled). "Ormnigent" may be a misspelling; confirm what Geoff means rather than guessing.
