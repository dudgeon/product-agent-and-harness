Downstream of intent the handoffs are documented everywhere; upstream, research → intent → plan across people is documented nowhere

  1. Agents sit at the same tasks in all six. Research, shape the intent, write the code, review and operate have a named agent or agent workflow in every ecosystem. Plan → code → review → release is documented in all six, mostly with a mechanism.
  2. No ecosystem has an agent that sets the goal, and the goal → intent handoff is inferred or unknown in five of six. The goal is a readable object only at Atlassian (Goals) and a reviewed process at Shopify (GSD, 2023 evidence). This band is where Geoff's reference workload, intent shaping, sits.
  3. Research → shaped intent or plan, across people, with the evidence attached, is undocumented in all six. Each ecosystem closes the gap another way: one person does all three tasks (Stripe, Anthropic, Intercom), a shared place stands in for a handoff (Shopify's thread, Anthropic's channel, Ramp's session), or an object carries the what without the why (Atlassian's work item, Intercom's PR description).
  4. The practices that close the gap depend on conditions a regulated org may lack: public-by-default sessions, engineers close to customers, tiny pods, strong test suites behind auto-approval, and transcripts available to mine. The evidence is first-party and self-reported in 104 of 105 source notes.

The shared pattern

  • Documented handoffs cluster downstream. Of 109 handoffs across the six maps, 79 are documented, 12 inferred and 18 unknown, and the unknowns sit almost entirely upstream of code: research → plan (Stripe, Anthropic, Atlassian, Intercom), goal → intent (Ramp), define → build across people (Ramp), the formal process ↔ the thread (Shopify), plus release and deploy mechanics that three maps could not find.
  • Where handoffs work, something shared is doing the carrying, not an agent: Stripe's documents and tool layer, Ramp's shared session, Shopify's public thread, Anthropic's open channel, Atlassian's work item, Intercom's PR description. The agent reads the shared thing; nobody hands the agent a research result.
  • The why is the first thing lost. Atlassian's work item carries the what; Intercom captures the why only at the PR; Ramp names the contract (data, requirements, prototype) but not its format; Anthropic's eval set carries examples without the reasoning. Shopify's thread keeps the why but only inside Slack, and not for private work.
  • Role blur is doing silent work. Stripe, Anthropic and Intercom all say the same tasks are done by one person more often than their titles suggest. The seam costs little there. It is the norm in the target org that decides whether it costs a lot.
