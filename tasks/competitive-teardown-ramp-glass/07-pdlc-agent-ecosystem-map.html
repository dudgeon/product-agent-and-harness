Where Ramp’s agents sit in the product lifecycle, task by task

Same frame as the Stripe map: rows are tasks, not job titles. At Ramp non-engineers write code through Inspect and PMs prototype in Glass. Each handoff is marked documented, inferred or unknown. Every figure is Ramp’s own; none is independently checked.

Ramp names the define → build contract, but not how it travels

  1. The contract is named. Geoff Charles: engineering wants the data, “the actual requirements that they can use for their coding agents, and a prototype”: “the next contract”. No source shows how it moves from a PM’s Glass session to an engineer’s Inspect session.
  2. Where context crosses people, Ramp carries the session itself. Glass sessions can be handed to a colleague, and every Inspect session is multiplayer with attributed prompts. Since October, Glass and Inspect run on one harness, Laminar.
  3. For small work, the people boundary goes away. Agent-run loops take feedback to backlog, plan, code, CI and the knowledge base, with a Slack check; “60% of UX issues … fixed within 24 hours”.
  4. The top of the chain is unrecorded. No tool is shown for setting the goal, and planning has no agent of its own.

Against Stripe: Stripe’s gap is between two agents (Kai → Orbit). Ramp’s tooling has fewer gaps: one workspace, shared sessions, one harness. Its public record leaves the same seam open in a different place: the hand-off from a define-stage session to a build-stage session when different people own them.

What it means for our options

  • Ramp’s answer to context across people is the shared session, not a hand-off artifact. It leaves open what happens when the next person needs a durable, reviewable artifact.
  • The define → build contract is a concrete candidate spec standard: evidence, requirements written for coding agents, and a working prototype. Its format is the open question.
  • One agent per stage, on one harness. Insight, Glass, Inspect, Review Buddy, Testo, Gadget, OCA, all on Laminar.
  • Split by size. Agent-run loops for small changes; human-shaped intent for large ones.
