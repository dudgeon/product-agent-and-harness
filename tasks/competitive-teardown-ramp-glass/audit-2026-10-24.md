## What Geoff should know

1. Glass's architecture is a moving target: April = desktop app on the Claude Agent SDK, laptop-side execution; October = cloud workers on Ramp's own provider-agnostic harness (Laminar). Any slide that says "Ramp built Glass on the Claude Agent SDK" is six months stale.
2. The "30% cheaper" number is Ramp Router's July claim, not a Glass outcome, and no data was published.
3. Every outcome number is Ramp's own; the architecture write-ups (Buchan in April, Kronick in October) are the high-signal material, and they disagree on how "vibe coded" the work was.
4. Ramp's own caveat on building a harness: cheap to build with coding agents, but you still need engineers on-call. No cost comparison exists.
