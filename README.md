# Product agent and harness

Research and strategy work on agent harnesses for product work: how product managers and other product roles could work with persistent, shareable sessions, standardised task agents and harnesses beyond a single vendor tool. The output is a strategy deck that informs a resource request: a menu of options by dimension, with the key questions that would decide among them, not one recommended implementation.

- [PROJECT.md](PROJECT.md): goal, phases, decisions and working rules.
- [research/](research/): one note per primary source (with links), an index and a theme register. Verbatim transcripts and full texts of third-party sources are omitted here; each note links to its original.
- [options/](options/): the options register, dimensions with options and key questions.
- [tasks/](tasks/): one note per piece of work, with its deliverables in a folder of the same name.

Written with Claude (Anthropic) agents directed by Geoff Dudgeon. Third-party content belongs to its owners and is summarised and quoted for research.
