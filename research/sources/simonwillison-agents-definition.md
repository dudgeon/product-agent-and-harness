## Relevance to the project
An independent practitioner's minimal definition ("An LLM agent runs tools in a loop to achieve a goal") that places the stop condition, not a step sequence, at the heart of an agent, and that reserves accountability for humans. Useful for terms by common usage and for the decision-rights dimension.

## Themes
- work-structure-spectrum: agents are bounded loops: "these are not infinite loops—there is a stopping condition."
- human-judgment-pm-jobs: accountability is "one key feature that remains unique to human staff"; humans set their own goals, agents do not.

## Key points
- Dropped "a goal set by a user" from the definition because sub-agents get goals from another LLM.
- Says OpenAI's Agents SDK is "a much closer fit to the 'tools in a loop' idea".
- Does not discuss workflows versus agents.
