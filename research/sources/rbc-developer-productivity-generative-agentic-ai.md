## Relevance to the project
A large bank's own account of using agentic tools on mainframe and legacy code inside its existing compliance controls. It shows the shape of bank practice (dependency mapping, change plans, test generation, vulnerability ranking) but gives no measured productivity, which is the gap the project must keep open.

## Themes
- agent-factory-sdlc: agents map dependencies and data flows, plan changes, support COBOL modernisation and generate test cases on the mainframe.

## Key points
- Tools: IBM watsonx Code Assistant for Z and IBM Concert, inside hybrid multi-cloud DevSecOps pipelines.
- Claimed outcomes are qualitative: faster idea-to-code, earlier security and compliance risk detection, fewer skills gaps on mainframe code.
- Governance: aligned with the bank's responsible-AI principles and with the same compliance controls on-premises and in cloud.
- Context numbers: a target of up to $1 billion enterprise value from AI by 2027; no productivity figure or method.
