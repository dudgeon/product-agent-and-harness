## Relevance to the project
A September 2025 tutorial on MCP for PMs across several clients (Claude Desktop connectors, Claude Code, Perplexity, Zapier): competitor pricing research through the Chrome connector, Figma MCP for design-to-code, Linear status in Perplexity, Postman's MCP to question your own APIs, and a "chief of staff" daily briefing assembled through Zapier's MCP. Mostly a snapshot of what was possible a year ago, so low relevance; the useful bits are the briefing recipe as a status-update job and Zapier's MCP as an aggregator that puts thousands of integrations behind one connector. All vendor capabilities are as the vendors announced them.

## Themes
- pm-tool-connectivity: two connection patterns shown side by side: per-tool connectors (Chrome, Linear, Figma, Postman) and an aggregator (Zapier MCP) where the user picks which Zapier actions Claude may call; the briefing prompt tells Claude to look in Zapier first and fall back to native connectors (section "Build your own personal Chief of Staff"). GitHub's MCP registry is noted as a source of official servers.
- status-update-agents: a daily brief combining calendar, Linear, Zendesk, Slack and news, optionally emailed each morning; and "what's in progress in Linear?" asked in Perplexity, turned into a Labs page for stakeholders.
- prototyping-agents-limits: Figma's MCP gives coding agents structured frame data (component hierarchy, variables, tokens, Code Connect links), but the rebuilt page "isn't 100% perfect" (Figma section).

## Key points
- Chrome connector: visit two competitors' pricing pages and produce a comparison artifact.
- Figma: extract design context, generate code from a selected frame, retrieve Figma Make resources.
- Postman MCP in Claude Code: ask questions about an API collection and draft example requests, with a suggestion to keep internal wiki pages current from it.
- Zapier MCP: authorise once, choose exposed actions, then one prompt assembles the briefing.
