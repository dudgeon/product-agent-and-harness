## Relevance to the project
goose v1.19.0 adds minimal, experimental MCP Apps support (draft SEP-1865, successor to MCP-UI, which goose supported in 2025): MCP servers can return interactive HTML UIs (forms, dashboards) rendered in sandboxed iframes inside the chat. Relevant to whether PM artifacts can be interactive surfaces inside a general agent; no Block-internal use is described.
