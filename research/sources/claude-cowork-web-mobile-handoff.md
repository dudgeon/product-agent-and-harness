## Relevance to the project
Anthropic moved Cowork sessions off the laptop: sessions and files follow the user across desktop, web and mobile, and scheduled tasks run with no device online, which answers the gap Cyera named (a personal agent stops when its owner's laptop closes) for the single-user case only. It bears on the deck's session-persistence and runtime-location options, and it states a review default ("Nothing ships until you've reviewed and approved it") with decisions pushed to the phone. It also gives a first-party usage figure: over 90% of Cowork use is not software development. This is a beta launch post; there is no detail on where cloud sessions run or how they are governed, and sessions are not described as shareable between people.

## Themes
- shared-persistent-sessions: "Close the laptop and head to your meeting; Claude keeps going"; start at a desk, check from the phone, pick up output anywhere; persistence is per user, not shared (section "What changes today").
- remote-agent-invocation: scheduled tasks "now run with no device online", e.g. Monday client prep at 6am leaving a follow-up email drafted but unsent (section "What changes today").
- human-review-gates: when Claude reaches "a call only you can make, it asks" via the phone; drafts can be redirected mid-run; "Nothing ships until you've reviewed and approved it" (section "What changes today").
- agent-as-service-many-surfaces: Cowork on desktop, web and iOS/Android; chat and Cowork now share one home with projects and artifacts together; desktop keeps local files and browser use (sections "What changes today", "Getting started").

## Key points
- Usage data (Anthropic's own analysis): more than 90% of Cowork use is not software development; business operations and content creation are the largest categories, roughly half of all usage together ("the work around the work").
- Examples given: quarterly spend reconciliation plus variance memo, contracts folder to renewals tracker with risks flagged, client deck from call transcripts and pipeline data.
- Desktop remains the "full" experience (local files, browser); web and mobile open Cowork to users who cannot install a desktop app.
- Rollout: beta starting with Max users; doubled usage limits to August 5 as a launch promotion.
- Single user quote from a Ramp customer-success employee about continuing a session on their phone.
- Limits: no mention of admin controls, data location of cloud-run sessions, or multi-person sharing of a running session.
