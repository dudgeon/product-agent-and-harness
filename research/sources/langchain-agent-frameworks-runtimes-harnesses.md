## Relevance to the project
Source of the framework / runtime / harness vocabulary, from a vendor that sells all three. Useful for the project's definition work, with the author admitting there is no clear agreed definition.

## Themes

## Key points
- Framework (LangChain): abstractions and standard structure; risk that poor abstractions hide what happens.
- Runtime (LangGraph): durable execution, streaming, HITL, persistence.
- Harness (DeepAgents): default prompts, opinionated tool handling, planning tool, filesystem.
