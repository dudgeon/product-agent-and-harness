## Relevance to the project

Defines the claude.ai 'project': knowledge base + custom instructions + chat history, shareable on Team/Enterprise. It is the nearest first-party analogue of a product-project container for a non-coding user, and its weaknesses (files, not typed artifacts) mark the gap a meta-harness could fill.

## Themes

- org-context-grounding: uploaded knowledge is the grounding, switching to RAG on paid plans when nearing context limits (up to 10x capacity per the page).
- shared-persistent-sessions: 'Can view' vs 'Can edit' sharing for Team/Enterprise.

## Key points

- Project = self-contained workspace: knowledge base (documents, text, code), custom instructions, own chat history; memory mentioned only for a beta version.
- Free accounts limited to five projects.
- A new beta version is rolling out starting with Claude Code, where a project is one conversation running parallel cloud threads (select Pro/Max users).
