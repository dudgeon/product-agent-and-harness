## Relevance to the project
Fortune's report of the Uber CTO's X post that AI cost per token fell while users of frontier tools quadrupled, "not because we've restricted access" but by treating efficiency "as an engineering problem rather than a budget problem" (caching, default-model change, model evals, per-hour usage and cost visibility). It is the governance backdrop to Cortana's launch: cost visibility rather than caps. Bears on cost controls built into the harness.

## Themes
- cost-control-routing: prompt caching, changing the default model, evaluating new models, and showing engineers their usage and cost per hour (CTO post as quoted).
- leadership-permission-mandate: earlier leaderboards ranked engineers by Claude Code usage; the CTO had gone "back to the drawing board" on spend (per The Information).
- outcome-measurement-gap: the CTO did not say whether total compute rose or fell.

## Key points
