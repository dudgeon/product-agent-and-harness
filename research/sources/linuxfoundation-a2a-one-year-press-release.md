## Relevance to the project
The headline adoption claim for A2A. It counts supporters and platform integrations (Azure AI Foundry/Copilot Studio, Bedrock AgentCore) but names no end-user production deployments, so it is evidence of ecosystem sponsorship rather than of agents actually delegating to each other in anger.

## Themes
- `remote-agent-invocation`: 150+ supporting orgs (up from 50+ at launch), v1.0 stable, Signed Agent Cards, SDKs in 5 languages, 22k GitHub stars; adoption 'spans supply chain, financial services, insurance, IT operations' with no named deployments.

## Key points
- Announced 2026-04-09 in San Francisco; A2A originated at Google and is hosted by the Linux Foundation.
- Named supporters: AWS, Cisco, Google, IBM, Microsoft, Salesforce, SAP, ServiceNow.
- Microsoft integrated A2A into Azure AI Foundry and Copilot Studio; AWS into Bedrock AgentCore Runtime.
- v1.0 features: multi-protocol, multi-tenancy, modernised security flows, migration path, Signed Agent Cards. LangGraph and CrewAI agents reportedly delegate sub-tasks without sharing memory.
- Describes A2A as complementary to MCP (also an LF project). Roadmap: interoperability spec, consolidated registry, testing tooling, security/deployment best practice.

## Could not verify
- No named customer production deployment and no usage metrics (calls, active agents) are given.
