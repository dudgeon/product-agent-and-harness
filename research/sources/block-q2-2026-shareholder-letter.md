## Relevance to the project
The letter makes Block's "own the harness, rent the model" stance explicit at board level: models are interchangeable, while "the harness, the data, and the distribution" are Block's. It reports that agentic AI "helped write and review nearly all of our production code changes" in June 2026 and announces Buzz, an internal system for agent collaboration and coordination. It also names what Block thinks becomes scarce when software is abundant (judgment, trust, depth of understanding, capability), which maps onto which product jobs stay human.

## Themes
- build-vs-buy / harness-portability: "We built goose in early 2024 to work with any model because betting on a single lab means inheriting its ceiling." All runs on "one internal platform for model access, routing, tools, and permissions, with evaluation systems" so a better model can be swapped in "the same day" (p.2). "To us the models are interchangeable, and everything that matters, the harness, the data, and the distribution, is ours." (p.2)
- agent-factory-sdlc: Builderbot "own[s] orchestration across Block's entire codebase"; in June, agentic AI helped write and review "nearly all" production code changes (p.2).
- human-judgment-pm-jobs: "AI will make software creation abundant. Judgment, trust, depth of understanding, and capability will become scarce." (p.2)
- vendor-claims-vs-independent-evidence: Moneybot "over 1 million weekly engaged accounts", defined in a footnote as accounts sending at least one message (including tapping a suggested prompt) in seven days (p.2, fn 5).

## Key points
- Buzz, launched July 2026: "our internally developed system for agent collaboration, communication, and code repositories", aimed at reducing "coordination drag" for teams of all sizes (p.2). This is the coordination layer the March essay described, in product form.
- The letter's argument: Block has run ML in production for 15 years (onboarding, fraud, underwriting); "Risk and lending were our first intelligence layer" (p.2). Generic AI on a rented, vertically integrated lab "creates generic outcomes".
- Financials: gross profit $3.17B (+25% YoY), adjusted operating income $864M (27% margin) (p.1). Cointelegraph (2026-08-06) reports Owen Jennings said on the call that code changes per engineer were up 150% versus the start of the year; not read in a transcript.
- Hardware (Cash App Tags NFC chips) gets equal billing with AI as "capabilities compounding fastest" (p.1).

## Notable quotes
- "no one differentiates with a model everyone else can rent." (p.2)
