## Relevance to the project
Gherkin is the established plain-language, machine-parseable format for acceptance criteria and is the notation Kiro uses (second-hand). It standardises one slice of a PRD (behaviour examples), not the whole document.

## Themes
- artifact-standardization: one Feature per `.feature` file; keywords Feature, Rule, Example/Scenario, Given/When/Then, Background, Scenario Outline; examples double as tests via step definitions.

## Key points
- Described as living documentation and executable specification.
