## Relevance to the project
A distribution layer for agents: register once, appear in every ACP client. It is a registry for whole harnesses, an analogue of skill marketplaces one layer up.

## Themes
- [[harness-portability]]: Claude Code, Codex CLI, GitHub Copilot CLI, OpenCode and Gemini CLI listed; agents added by pull request and available to all ACP clients (Zed, JetBrains 2025.3.2+).
- [[skills-marketplace]]: 'the missing distribution layer' for agents, with updates pushed without client review cycles.
