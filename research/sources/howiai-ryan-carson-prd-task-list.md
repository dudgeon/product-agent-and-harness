## Relevance to the project
An early (May 2025) example of a PRD as the context file for a coding agent: a "three-file system" in Cursor where the AI writes a PRD, turns it into a task list, and then works through tasks one at a time with the human checking each step. Carson open-sourced the prompts (the snarktank/ai-dev-tasks repo linked in the show notes). It is an individual founder's workflow and only show notes were available, so it adds little beyond the Notion and spec-kit material, but it dates the PRD-to-tasks pattern. Bears lightly on intent-shaping-and-spec.

## Themes
- prd-agents: demo of creating a PRD with Cursor (03:25) and generating a task list from it (11:00).
- agent-ready-intent: "slowing down to provide proper context is the secret to speeding up" (episode description); task lists and change management (18:07-20:00).
- docs-as-code-prd: the PRD and task list live as files the agent reads in the repo (three-file system, description).

## Key points
- Also covers MCPs for front-end testing (Browserbase, Stagehand), Repo Prompt for precise context control, and Task Master (21:50-26:45).
- Claim from the description: founders "can now build entire companies with minimal engineering teams".
