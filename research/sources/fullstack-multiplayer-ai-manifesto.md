## Relevance to the project
A position piece arguing that agent sessions should be multiplayer: "teammates can participate in the same agent session, with shared context", so the next person "can join the conversation and continue the work" rather than receive a forwarded answer (catalogue item 2). It is the clearest statement of the "join a running session" thesis outside Shopify/Stripe/Block, and it concedes the gap: "No platform meets the entire manifesto today." The author builds a commercial multiplayer platform (Superconductor; also an AI Engineer World's Fair 2026 talk), so this is advocacy, with no data.

## Themes
- shared-persistent-sessions: shared session with shared context and tool access; reviewers can ask the coding agent why it made a decision; PMs can join with a requirement; sessions are preserved so work can resume (principles; vendor, 2026-09-08)
- public-by-default-agent-work: sharing agents "raises questions about permissions, privacy, and accountability" (risks paragraph)
- identity-delegation: the full manifesto reportedly covers governance and ownership of accumulated team knowledge; not detailed on the summary page

## Key points
- Proposes the same model for proposals, financial plans and campaigns, not only code.
- YC's Fall 2026 request for startups reportedly makes a similar "multiplayer AI" call (a teammate steps into a live run, redirects it, hands it off) per a Wavect review; not opened.
