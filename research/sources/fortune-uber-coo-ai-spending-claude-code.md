## Relevance to the project
Uber's COO (on the Rapid Response podcast) says the link between Claude Code usage and more useful consumer features "is not there yet" and that without it "that trade becomes harder to justify"; the CEO separately put agent-built committed code at about 10%. It is the executive pressure behind Uber's later outcome-instrumentation and cost work. Bears on outcome measurement.
