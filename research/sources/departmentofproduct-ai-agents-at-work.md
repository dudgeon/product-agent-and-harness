## Relevance to the project
An early-2025 tutorial on no-code agent builders (Gumloop, Zapier Agents, Extruct, Microsoft Copilot Studio) applied to PM-adjacent chores: competitor tech-stack reports, market research, speaker notes, and keeping an achievements log. It is dated and mostly about trigger-plus-actions automations rather than PM agents, so it matters little to the strategy. It does show the 2025 "no-code SaaS" route to agents (one of three build routes it names: framework, from scratch, no-code) and an early instance of an agent reached from a browser extension over the page in front of the user. All results are the author's own trials.

## Themes
- non-engineer-builders: the no-code route: Gumloop flows (scrape a site, analyse with BuiltWith and an LLM, write a report; scheduled or run across a spreadsheet of competitors); Zapier Agents built from "behaviours" (natural-language instructions, a trigger, actions across thousands of integrations) plus data sources.
- org-context-grounding: agents are more useful when given data sources (Jira, Notion, Docs, CRM); the speaker-notes example relies on the agent knowing competing priorities from those sources; Copilot Studio agents connected to SharePoint and Dynamics 365.
- agent-as-service-many-surfaces: the Zapier Chrome extension runs any Zapier agent over the page open in the browser (e.g. a slide deck).
- research-synthesis-agents: Extruct for natural-language company search and enrichable tables; the author found people and pricing accurate but website traffic wrong for a small company.

## Key points
- **Opening stat:** at a WSJ CIO summit, 61% were experimenting with agents and 21% not using them at all (second-hand).
- **Five use cases:** competitor tech-stack report; job search plus a Slack-emoji-triggered achievements log feeding a resume generator; speaker notes for an open presentation; market research; assigning work to coding agents (GitHub Copilot Agent Mode and the then-upcoming "Project Padawan" for assigning whole tickets).
- **Author's friction note:** switching between Zapier, the resume and the job description felt fiddly, which the browser extension addresses.
