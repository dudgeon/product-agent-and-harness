## Relevance to the project
The UK financial regulator states that agentic systems need "continuous, conditional assurance", that senior managers stay personally accountable for AI, and that it will build a "trusted framework for agentic finance" covering agent identity, delegated authority, accountability and execution. It also plans a Handbook API for machine-readable rules. For a dependency agent in a UK bank this is the regulatory frame: delegated authority must be explicit and attributable, and the regulator itself is moving rules toward machine-readable form.

## Themes
- identity-delegation: the trusted framework will cover "agent identity, delegated authority, accountability and execution", developed with industry, regulators and frontier labs (future work).
- decision-rights-for-agents: firms need "clear accountability, risk-based controls, human oversight, escalation triggers", with senior managers personally accountable.
- governance-as-code: FCA plans a Handbook API for machine-readable rules and machine-readable data collection; AI tools to supervise ~60,000 AML firms joining its remit in 2028 and an AI "market first responder" agent for ~9,000 small wholesale reporting firms.
