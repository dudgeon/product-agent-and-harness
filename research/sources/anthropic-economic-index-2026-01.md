## Relevance to the project
Usage data splitting directive/automation-style use (API) from iterative, augmentative use (consumer chat): a measured version of "delegated structured work" vs "back-and-forth thinking work". Useful as a rough population baseline, not as a taxonomy of team processes.

## Themes
- work-structure-spectrum: Claude.ai 52% augmentation vs 45% automation (Nov 2025; augmentation was 56% in Jan 2025, automation overtook it in Aug 2025); first-party API about three-quarters automation; directive use 64% on API vs 32% on Claude.ai.
- evals-autonomy-trust: task success 67% on Claude.ai vs 49% on API; success falls with task length; fitted 50% horizon about 3.5 hours (API) vs about 19 hours (Claude.ai), attributed to multi-turn feedback (extrapolation).

## Key points
- Sample: Claude.ai and 1P API traffic, 2025-11-13 to 11-20. The rise in augmentation was mainly task iteration (edit/rewrite/revise).
- API use concentrated in automation-friendly work such as security analysis, testing, code review.
