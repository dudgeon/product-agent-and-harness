## Relevance to the project
Uber's May 2026 hiring copy for its AIFX team names the direction behind Minion: a multi-agent runtime inside DevPods with "persistent background agents, swarm orchestration, cross-agent context passing", the MCP platform layer, and a Skill Marketplace that encodes tribal knowledge as "loadable, composable expertise". It is first-party intent rather than shipped capability. Bears on agent-to-agent hand-off and skills as captured know-how.

## Themes
- skills-marketplace: team owns the Skill Marketplace, encoding tribal knowledge so engineers become productive in any monorepo.
- tacit-knowledge-capture: skills framed as "loadable, composable expertise" from tribal knowledge.
- agent-control-plane: team owns "the MCP platform layer"; consolidating code-mcp, docs-mcp and developer lifecycle MCPs.
- shared-persistent-sessions: "Persistent background agents" working in parallel rather than one-shot.
- handoff-context-transfer: "cross-agent context passing" in a DevPod multi-agent runtime.

## Key points
- Agent runtime listed as Claude Code, Codex and "Minions, our background agent orchestration system for autonomous code generation".
- Direction: from IDEs to "Agentic Dev Environments (ADEs), where AI agents are first-class participants" in the SDLC.
- Base USD 267-297k; SF/Sunnyvale (Seattle for pay purposes).
