## Relevance to the project
The design director's account of Intercom's "shape the intent" row: designers "primarily working in code" with Claude Code, Figma used "more like a whiteboard", prototypes built in production environments with live data, and the design system (Surge) treated as agent infrastructure. It states the human/agent split explicitly: agents "own the middle, the build"; people decide which problems matter, set intent and hold the quality bar. Handoffs become "less definitive", replaced by "tighter briefs at the start, fast review cycles, and clear criteria for what good looks like".

## Themes
- spec-becomes-prototype-and-evals: "Our designers are now primarily working in code"; the team is "no longer defaulting to Figma"; a designer prototyped fine-grained tint controls in Claude Code that would normally take "weeks of back-and-forth with engineering".
- human-judgment-pm-jobs: agents "cannot decide which problems matter, set intent, resolve trade-offs, or hold the bar for quality"; design leaders move "from gatekeeper to orchestrator".
- pm-persona-role-expansion: PM, design and engineering boundaries blurring; the 2x initiative expects non-engineers to contribute to the codebase (practice 3).
- legible-org-for-agents: "Design system as agentic infrastructure": components, libraries and guidelines are the base agents build on; the Surge playground lets designers prototype with production components (practice 4).

## Key points
- Cites "90% of pull requests" authored by Claude Code at Intercom (March 2026).
- Five practices: AI fluency (training, demos, office hours, protected time); challenge orthodoxies (code-first, not Figma-first); cross-functional tooling sharing; design system as agentic infrastructure; "from makers to curators".
- Handoff change: "Definitive handoffs and perfection on the first pass matter less"; deliberate pauses for evaluation replace accidental ones.
