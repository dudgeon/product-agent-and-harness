## Relevance to the project
A third-party write-up of Angie Jones's MCP Developer Summit talk (2025). Superseded by the fuller New Stack report ([thenewstack-block-12000-employees-ai-agents](thenewstack-block-12000-employees-ai-agents.md)); kept for the context-management details and the "15+ job functions" figure.

## Themes
- enterprise-admin-controls: internal allowlist blocks unauthorised MCP servers; all internal servers use SSO-based OAuth with browser flows, no manual API keys.
- single-agent-many-skills: only relevant MCP servers enabled per prompt; summariser for long sessions; context-window progress bar.
- enablement-by-product: auto-install and auto-update on every Block laptop; 60+ internal servers bundled; Hack Week volunteers built servers.

## Key points
- Use cases: Snowflake natural-language queries, Databricks lead distribution, PagerDuty incident triggers, Glean knowledge; shareable recipes and a web-app deployer for non-engineers.
