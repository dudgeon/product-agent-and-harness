## Relevance to the project
Independent commentary that independent harnesses are economically disadvantaged because Claude subscription credit only works inside Claude Code. For a project reducing dependence on Claude Code, this is a concrete cost: Claude users of other harnesses pay API rates on top of any subscription.

## Themes
- harness-portability: subscription credits usable only in the vendor harness; Pi users pay API fees; OpenAI credits work with compatible third-party tools.
- build-vs-buy: article argues business strategy, not technical merit, decides whether independent harnesses survive.

## Key points
- Terminal-Bench results cited as putting Pi on par with Cline and OpenCode on several open-weight models.
- Workarounds: pay twice, use GPT/open-weight models, or wait for policy change.
