## Relevance to the project
Another vendor using 'meta-harness', with a different emphasis: cross-repo awareness (repository graph) and a session graph so anyone can resume anyone's session with any agent. Relevant to persistent/shared sessions across harnesses.

## Themes
- [[meta-harness]]: 'agent-agnostic meta-harness', compared to Next.js as a meta-framework on React.
- [[shared-persistent-sessions]]: session graph records every session so work can be resumed 'by anyone, on any machine, with any agent'; decisions recorded for agents.
- [[harness-portability]]: names no specific agents.
