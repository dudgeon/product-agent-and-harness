## Relevance to the project

GitHub's 'project' is a thin planning layer over issues and PRs at user/org level, not a container of documents. Combined with docs-in-repo (Spec Kit), it shows the repo, not the project board, being the home of long-form artifacts.

## Themes

- work-structure-spectrum: items are issues, PRs or draft issues with up to 50 custom fields; table, board and roadmap views.

## Key points

- Project = adaptable table, board and roadmap integrating issues and PRs, at user or organisation level; two-way sync with issues.
- Built-in automation workflows; GraphQL API and GitHub Actions for advanced control; insights charts.
- Sub-issues not covered on this page.
