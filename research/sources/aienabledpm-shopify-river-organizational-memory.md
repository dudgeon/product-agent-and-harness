## Relevance to the project
A PM-audience reading of "Learning on the Shop floor". **It restates Tobi's claims.** The free half frames River as "a public learning surface" and turns it into a PM roadmap checklist (which failures should become instructions, which context should become skills). The second half is paywalled. It is the only source naming a **#river** channel that new hires browse.

## Themes
- `org-learning-loop`: in "the private-agent model ... the learning stays mostly with that person". In River's model, "the channel history becomes onboarding."
- `compounding-context-repo`: many agent failures "are context failures, instruction failures, workflow failures, permission failures, naming failures, and taste failures", which an organisation fixes by making knowledge explicit, not by changing models.
- `agent-led-intent-shaping`: PM questions: "Which repeated failures should become instructions? Which team-specific context should become a reusable skill? ... Which human review comments should become future guardrails?"

## Key points
- It names categories that should remain private: "HR, legal, compensation, sensitive customer data, security incidents, and anything involving personal context."
- Channel names: "#tobi_river" (100+ people) and "#river" (new hires scroll it), attributed to Tobi.
- The same authors later wrote "Jev Shows That Not Every AI Call Should Generate Text" (2026-09-24), about Shopify's Jev classifier. That piece was not read.
