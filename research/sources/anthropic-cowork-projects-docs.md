## Relevance to the project

The Cowork 'project' is the most explicit first-party project definition for knowledge workers: description, folders, instructions, links, linked chat projects and project-scoped memory. It is local-only and unshareable, which is the main structural gap for team-level product work.

## Themes

- memory-architecture: a dedicated project-scoped memory store persisting across sessions; archiving deletes metadata including memory but not local files.
- shared-persistent-sessions: projects live on the computer only, not synced or shared; claude.ai projects are shareable on Team/Enterprise and can be linked, not merged.

## Key points

- Project holds: description (Dispatch reads it to choose a project for a task), folders (one or more local), instructions, links, linked Chat projects, memory.
- Start from scratch, import a claude.ai project, or use an existing folder. Files up to 50 MB readable.
- Dispatch can route background tasks into a project.
