## Relevance to the project
First-party, speaker-reported account of how an incumbent's PMs use agents, mapped to PM jobs: comms/status (CEO self-serves launch timing via Rovo; PM-built weekly-update agent), feedback triage and discovery synthesis (Rovo agent categorized 900+ feedback items), prototyping/intent shaping (Loom -> work item -> coding agent), and PM-owned evals. Bears on which PM jobs to build agents for first and on the "rowing vs steering" question for PM roles. Limits: vendor CPO at a friendly event, anecdotes with no baselines.

## Themes
- pm-job-stable-methods-change: "the job of a PM is really the same as it always was... It's how we do it that's changed" (02:30).
- org-context-grounding: tools work because they see the org's context via Atlassian's "teamwork graph" (03:31, 16:33).
- status-update-agents: PM built an agent in the product to give weekly updates, no longer writes them (11:32); CEO asked Rovo about a launch date and apologised for wasting their time (04:01).
- feedback-triage-agents: Jira agent in Slack triages bugs and feedback to a coding agent (15:03); Rovo agent categorized 900+ customer-insight items, quality "happily surprised" (15:33).
- non-engineer-builders: Confluence PM with no prior coding landed 26 PRs in a month via an engineer-built harness and an isolated repo (06:32-09:32); on Jira PMs did not check in production code (12:33, 16:03).
- outcome-measurement-gap: "we haven't figured it out"; measures PRs deployed, features delivered, usage, OKRs (19:35-20:35).

## Key points
- Three cases: Confluence (Remix 6 weeks, Slides 8 weeks vs ~6 months before; PM rowing, checking in code; evals 2x throughput; Figma MCP + coding agent fixed ~14 design bugs/hour; test creation half a day -> 10 minutes) (06:02-09:32). Rovoclaw 0-to-1 (PM and designer vibe-coded alpha; PM stepped back from coding to steer: direction, prioritizing, unblocking) (10:02-12:02). Jira (about 3x throughput; 22 user-facing features in ~10 weeks; Loom -> auto work items -> cloud coding agent; feedback triage) (12:33-16:03).
- PMs now do: prototyping, evals, deeper customer feedback, consuming more information; no longer: manual updates, hand-compiled research, slides from scratch (16:03-16:33).
- Upskilling: AI fluency index (six capabilities, levels 1-5; development not ladder), quarterly "AI builder weeks", 1,000+ people, 120+ workflows, "builder week in a box" on Atlassian's site (17:03-19:35).

## Notable quotes
- "None of that has really changed. It's how we do it that's changed." (02:30)
- "we haven't figured it out. I don't think anyone has figured it out." (19:35)
