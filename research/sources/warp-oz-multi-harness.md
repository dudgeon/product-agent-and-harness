## Relevance to the project
A commercial cloud-agent control plane that runs Claude Code and Codex next to its own agent, with shared triggers, environments, skills/rules, audit and per-team credit caps. It is the closest commercial analogue to Omnigent, hosted and with a self-hosted option.

## Themes
- [[meta-harness]]: 'first control plane that runs Claude Code, Codex and Warp Agent side by side'; only Warp Agent can be the parent in multi-harness runs (docs).
- [[harness-portability]]: Skills and Rules, environments, secrets and triggers (Slack, Linear, schedules, CI, API) shared across harnesses.
- [[shared-persistent-sessions]]: each run produces a transcript and shareable session in the cloud dashboard; cross-harness agent memory in research preview.
- [[cost-control-routing]]: per-team billing, individual credit caps; but Claude Code/Codex run on your credentials, so Warp's cost summaries do not fully show inference charges (docs).

## Key points
- Multi-harness support free in beta; third-party harnesses need a paid plan. Deployment options: self-hosted Kubernetes, Docker, or direct execution.
- CEO Zach Lloyd: 'Companies shouldn't have to bet their future on a single model or harness.' No customers or pricing named.
