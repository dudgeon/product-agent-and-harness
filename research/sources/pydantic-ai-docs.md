## Relevance to the project
A type-safe, model-agnostic Python agent framework that now also ships a Harness (memory, guardrails, sub-agents, planning, compaction, a Coder agent) and durable-execution integrations. Another sign that frameworks are converging on harness features.

## Themes
- agent-frameworks: features, durable execution options, evals, graph, harness.

## Key points
- Typed outputs/deps/tools with validation-driven retries; virtually all model providers.
- Durable execution on Temporal, DBOS, Prefect, Restate, AWS Lambda, Airflow and others; Harness StepPersistence snapshots steps.
- MCP as core capability; Pydantic Evals incl. online evaluation; Pydantic Graph.
- Capabilities bundle tools, instructions, hooks and settings; Harness adds memory, guardrails, sub-agents, planning, compaction, Coder agent.
