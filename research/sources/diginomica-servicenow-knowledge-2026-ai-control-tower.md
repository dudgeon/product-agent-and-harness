## Relevance to the project
ServiceNow positions AI Control Tower as a cross-vendor governance layer (discover, observe, govern, secure, measure) over agents on AWS, Azure, Google Cloud, SAP, Oracle, Workday and more, and opens its "system of action" to outside agents (Claude, Copilot, in-house) through a GA MCP server, with Anthropic as first design partner connecting Claude Cowork. For a regulated company already on ServiceNow, this is a route where a Claude-based agent triggers governed, audited workflows (approvals, catalogue actions) rather than raw API calls.

## Themes
- agent-control-plane: 30 new connectors; runtime monitoring (Traceloop acquisition); five risk frameworks aligned to NIST and the EU AI Act; Veza access graph across human, non-human and agent identities; cost and ROI dashboards; AI Gateway for third-party AI connecting via MCP.
- remote-agent-invocation: Action Fabric MCP Server (GA, in every Now Assist and AI Native SKU) lets outside agents trigger workflows, playbooks and approvals, identity-verified and auditable.
- identity-delegation: re-scoping workflow when a vendor updates a model or agent.

## Key points
- Microsoft Agent 365 integration in preview; Project Arc (NVIDIA desktop agent) early preview.
- Author's critique: implementation gap in siloed enterprises; wants customer evidence; Microsoft, Salesforce and Google pursue similar theses.
- Vendor figures ($500M AI value, 1,600 internal AI assets) unverified.
