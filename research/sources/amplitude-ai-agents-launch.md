## Key points
- Case 3: Global Agent (plain-language questions; builds dashboards, investigates root causes, available in Slack), four specialized agents that run in the background (press release: Dashboard Monitoring, Session Replay, Web Experimentation, AI Feedback; the blog lists dashboard, session replay, customer feedback and web conversion agents). The docs say schedules are configurable when setting agents up; "scheduled" is not the vendor's label. MCP connects Amplitude data to Claude, Cursor, ChatGPT, Figma, Notion and more (press release also names Lovable, GitHub, AWS Kiro, Atlassian Rovo). Jobs: metrics review, feedback synthesis.
