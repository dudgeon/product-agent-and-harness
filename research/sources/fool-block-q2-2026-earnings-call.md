## Relevance to the project
The one public number at Block that measures product output rather than code: "Square ... shipped 130 features in the first half of 2026", "up more than 3x" on the first half of 2025, attributed by Jack Dorsey to Goose, MCP, Buzz "and everything else that we've built internally". Alongside "a Block AI is involved in basically every single production code change or production code review" and code changes per engineer up 150% since January, it is the best Block evidence for release-stage outcomes, and also shows that "features shipped" is the only product-level measure offered.

## Themes
- outcome-measurement-gap: features shipped (130 in H1 2026, more than 3x H1 2025) is a throughput measure; no customer-outcome or quality measure for those features is given (Dorsey answer on Cash App Tags).
- human-review-gates / agent-factory-sdlc: "a Block AI is involved in basically every single production code change or production code review" (same answer).
- vendor-claims-vs-independent-evidence: Dorsey says quality and speed "used to conceptually be at odds" and are not any more "given how the AI tools are flowing through"; no data offered on quality.

## Key points
- Cash App Tags (NFC hardware) cited as a product brought to market "incredibly quickly", with a seller-reaction anecdote from the first prototype (Owen Jennings, then Dorsey).
- Buzz: "a very small team" built it; it is used internally "to develop" and "to collaborate"; roadmap includes full Git hosting; Block intends to monetise Buzz, Managerbot and Moneybot (Dorsey, Jennings).
- Model agnosticism as cost control: Goose lets Block use whichever frontier or open model fits; "You don't need the most leading edge model now for the vast majority of ... knowledge work" (CFO answer).
- Dorsey: sellers "are all interested in building" and are already using AI tools; Buzz is pitched to them too.

## Notable quotes
- "we shipped 130 features in the first half of 2026. That's up more than 3x relative to the first half of 2025." (Dorsey, Q&A on Tags)
