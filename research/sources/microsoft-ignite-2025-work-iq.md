## Relevance to the project
Microsoft's launch framing for Work IQ, Fabric IQ and Foundry IQ as "intelligence layers" that agents share. It is a context-layer play (agents read the same organisational graph and memory), not a coordination medium: nothing describes agents handing work to each other through it. Useful to separate "shared context layer" from "shared work record" in the pattern catalogue.

## Themes
- org-context-grounding: Work IQ is "the intelligence layer that enables Microsoft 365 Copilot and agents to know how you work", built "on your data, memory and inference" across email, files, meetings and chats; APIs let builders "build agents tuned to your unique workflows"; Fabric IQ puts operational and analytical data "under one shared model tied to business meaning"; Foundry IQ is a "single endpoint for knowledge" for grounding agents.

## Key points
- Agent 365 is positioned as the control plane to "observe, manage and secure" agents from any platform.
- No schemas, no write paths, no outcome data in the post.
