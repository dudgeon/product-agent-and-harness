## Relevance to the project
Press report of Angie Jones's All Things Open 2025 talk on rolling goose out to all ~12,000 Block employees in eight weeks. It gives the clearest account of the distribution mechanics (internal software center, auto-install and auto-update), the pre-approved MCP catalogue (60+ built in a week, 100+ by October 2025), automatic tool enabling, and the two-Slack-channel adoption model. Independent reporting, but entirely sourced from Block's talk (sponsored topic: Tabnine).

## Themes
- enablement-by-product: first attempts failed because non-technical staff could not install or authenticate; fix was goose in the internal software center: "if you have a Block laptop, you have Goose. It just works."
- org-learning-loop: a help channel and an inspiration channel for "success stories or cool workflows or clever prompts"; the latter was "one of the best organic drivers of adoption"; team-specific workshops (sales ops differs from support).
- enterprise-admin-controls: a small task team built the internal servers people needed; "over 60 internal MCP servers" by the end of that week, "today, we're over 100", all pre-approved.
- harness-portability: employees choose among OpenAI, Anthropic, Google and Meta providers; marketing prefers ChatGPT for writing, engineers Claude.
- single-agent-many-skills: users enabled every tool "just in case", making the agent slow; Block added automatic tool management (enable only Calendar and Asana for a scheduling question) and auto-summarisation.
- non-engineer-builders: a non-engineer built her own MCP server and had no GitHub account to submit it.

## Key points
- Examples: security analyst detecting fraud in plain English over the warehouse; sales ops redistributing 80,000 records in an hour instead of days; incident pattern analysis; procurement help.
- Origin: Bradley Axen's function-calling experiments; Block became an MCP launch partner and rewrote goose for MCP.
