## Relevance to the project
A designer-led, bottom-up AI adoption programme inside a product company (Pendo): a Slack message sent from paternity leave, then synchronous workshops plus asynchronous sharing channels, a central AI knowledge centre, adoption measured with metrics and sentiment surveys, and a "golden path" for tool use agreed with legal, security and finance. It bears on adoption-model (champion-led versus top-down) and on the governance step that enterprises need before tools spread. Downgraded from medium because no transcript was available: the substance is only in the show-notes outline.

## Themes
- org-learning-loop: "two-pronged approach" of synchronous workshops and asynchronous sharing channels (12:25, 22:00); a centralised AI knowledge centre (33:48, Confluence and Slack are referenced).
- enablement-by-product: the guest built an MCP server to demonstrate what AI could do with company systems (35:58), a demo-as-enablement move.
- outcome-measurement-gap: adoption measured "with sentiment surveys and clear metrics" (24:43); which metrics is not stated in the notes.
- pm-tool-connectivity: the MCP server demo (35:58) implies connecting agents to internal product data; no detail in the notes.

## Key points
- Started from a personal epiphany using AI coding tools on paternity leave and a single Slack message that "kickstarted" the transformation (01:38-05:00).
- A "golden path" for AI tool use created with legal, security and finance (show notes, what you'll learn). Relevant to large regulated settings as the gate before tools spread, but no detail on what it contained.
- Argues AI lets designers move beyond MVP thinking (18:41) and that technical understanding matters for non-technical roles (44:08).
- Tools referenced: Cursor, Bolt, Claude, ChatGPT, Midjourney, Gemini (show notes).
