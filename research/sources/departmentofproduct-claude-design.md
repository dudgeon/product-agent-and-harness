## Relevance to the project
A hands-on first look at Claude Design (research preview, April 2026), which matters to the project as a separate surface for the prototyping and stakeholder-deck jobs, grounded in a design system imported from a repo, with a one-command handoff of the result into Claude Code. It offers a compact mental model of the Claude product family for a PM audience (Chat, Cowork as a worker you delegate to, Code as an engineer, Design as where you experiment). The tests are the author's own on a mock app; the Figma stock and board-resignation claims are second-hand press.

## Themes
- org-context-grounding: the design system is the core setup step: company blurb plus a GitHub repo (or subfolder), local code folder, .fig file (parsed locally, per the post) and assets; Claude extracts components into an editable library ("surprised it worked so well").
- prototyping-agents-limits: onboarding flow, landing page and a 3D component came out well from short outcome-oriented prompts; the stakeholder deck was "passable" but full of AI clichés, and PPT export failed repeatedly (sections on the deck).
- pm-persona-role-expansion: closes on the view that model-native design tools are "closing the gaps between each of the traditional product disciplines".
- harness-portability: "handoff to Claude Code" gives a command that pulls the design from the Anthropic API into a local copy, so work moves between surfaces rather than being trapped in one.

## Key points
- Interaction: chat for broad or structural changes and variations; inline comments on canvas elements for precise edits; a "Tweaks" panel for quick adjustments.
- Prompting advice relayed from Anthropic docs: state goal, layout, content and audience; Claude asks clarifying questions, which the author found close to what a product team would discuss.
- At the time it was a standalone research preview reached from the Claude chat sidebar, not in the desktop app.
- Five examples: mobile onboarding (offered several visual directions), landing page, animated 3D visual, a 10-page stakeholder deck comparing three directions against an activation goal, and the Claude Code handoff. A gallery of 25+ community examples is linked.
