## Relevance to the project
A feature request to treat an Omnigent project as a team and its Canvas tab as the team's board, with a lead agent that hands work to specialist agents. It shows where the maintainers and users are taking the Canvas: coordination among coding agents. The canvas-coach concept film takes the same board in a different direction, toward a product manager's planning artifacts.
