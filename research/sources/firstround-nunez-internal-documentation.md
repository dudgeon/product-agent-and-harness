## Relevance to the project
A former Stripe docs leader on why internal documentation fails and how to build the habit: knowledge "trapped in an early hire's head", "hero" employees, docs debt, and the observation that companies admire Stripe's writing culture but can't copy it because internal docs are hidden. Pre-AI evidence that capturing tacit knowledge is a cultural and incentive problem, not a tooling one; Nunez put a documentation expectation on each level of the job ladder. Bears on the context-creation hypothesis (against a pure-tool answer).

## Themes
- tacit-knowledge-capture: "Mission-critical knowledge trapped in an early hire's head is an all-too-common problem"; capture falls to "the wish-list pile" on small teams; recommends making documentation part of career expectations.
- legible-org-for-agents: external docs get investment "because users depend on it", internal docs don't: a "documentation caste system".
