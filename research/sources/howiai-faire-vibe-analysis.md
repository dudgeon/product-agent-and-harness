## Relevance to the project
Faire's data leaders demo AI-assisted analytics: investigating a conversion drop by searching docs and code, a semantic layer so AI understands business data, Cursor plus MCPs to query, chart (Mode) and write up (Notion), a custom agent that documents experiment results in a standard report, and survey design and analysis. Topically it bears on the analyst hand-off into a PM harness (analyst agents in) and on context-and-memory (the semantic layer as grounding). Filed as low only because no transcript was available: everything below comes from the show notes, so the note carries no first-hand detail.

## Themes
- metrics-review-agents: demos of investigating a sudden conversion drop (05:46), analysing a new feature's performance in Cursor (18:55), and a custom agent that automates experiment-result documentation into standardised reports (44:39) (show-notes chapter list).
- org-context-grounding: "how semantic layers make AI tools more effective for data analysis" (26:27); Cursor used as "the ultimate context engine" over the codebase to explain metric changes (12:40); the guests argue every team member, not only engineers, should have repository access (show notes, "What you'll learn").
- pm-tool-connectivity: MCPs connect the AI to Snowflake, Mode (visualisation, 34:17) and Notion (structured analysis docs, 37:04).
- research-synthesis-agents: AI-assisted design and analysis of customer surveys (Qualtrics referenced) (53:10).

## Key points
- Workflow shape, as listed: enterprise AI search over docs to find what changed (05:46), ChatGPT Deep Research over code changes (09:05), Cursor for code and data analysis, semantic layer, MCPs to data tools, Mode dashboards, Notion executive documents, custom experiment agent, surveys.
- Framing: analytics is more than data manipulation (04:14); target is "executive-ready insights ... without writing SQL from scratch" (subtitle).
