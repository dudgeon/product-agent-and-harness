## Relevance to the project
Uber's own October 2026 description of what the AIFX team owns: the AIFX CLI and agent harness layer, Minion, uReview, and "agent governance & cost controls" (model routing, spend caps, usage analytics, evaluation). Cortana and personas are not listed, which suggests Cortana sits with a different team or is not named in hiring copy. Bears on how Uber divides harness, background agent, review and governance ownership.

## Themes
- agent-control-plane: team owns "agent governance & cost controls: model routing, spend caps, usage analytics, and evaluation".
- harness-portability: AIFX CLI is "a single way for engineers to install, configure, and run AI coding agents" with consistent settings, plugins, skills and MCP servers; preferred experience in Claude Code, Codex, OpenCode, MCP.
- agent-factory-sdlc: role defines "how AI agents plan, build, review, verify, and ship software at Uber"; durable execution (Cadence, Temporal) preferred.
- cost-control-routing: spend caps and model routing are a named platform responsibility.

## Key points
- Team: AI Foundations & Developer Experience (AIFX), Developer Platform; "a centralized, cross-monorepo team". Locations SF, Sunnyvale, Seattle; base USD 232-258k.
- Minion described as "a platform that runs autonomous coding tasks at scale", from bug fixes and migrations to CI repair.
