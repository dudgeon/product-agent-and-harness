## Relevance to the project

Linear's strategy layer above projects, with a health signal derived from the latest update. Shows a 'status update' as a first-class, structured artifact that rolls up, directly relevant to status-update agents.

## Themes

- work-structure-spectrum: initiative > project > issue, with team-led sub-initiatives rolling up to company goals.

## Key points

- Initiatives are workspace-level containers for projects tied to a shared objective; IDs like I-<n>.
- Initiative health (on track / at risk / off track) is set by its latest update; project colour status likewise (green/yellow/red/gray when no current update).
- Resources section attaches documents and links.
