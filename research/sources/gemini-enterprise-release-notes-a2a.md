## Relevance to the project
Dates when Gemini Enterprise, Google's enterprise agent app, made A2A a governed, admin-registered route: agents registered over A2A sit beside MCP servers in Agent Registry and can be imported for central management. This is the clearest "enterprise agent host as A2A client" product, but it is a Google product consuming A2A agents, and no customer traffic figures are given.

## Themes
- `remote-agent-invocation`: 2026-08-17: registering A2A (and A2UI) agents moves from Public Preview to GA. 2026-09-03: Workflow Builder (formerly Agent Designer) GA with "Import existing A2A and ADK agents" for centralised management and governance. 2026-09-08: Marketplace search entry links to "Add and manage A2A agents from Google Cloud Marketplace".
- `scoped-governance-containers`: 2026-06-25: admins select "A2A agents or MCP servers" from Agent Registry to add to Gemini Enterprise apps, i.e. one governance list for both routes.
