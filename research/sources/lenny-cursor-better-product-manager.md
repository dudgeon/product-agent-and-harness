## Relevance to the project
A PM (Dennis Yang, Principal PM for Generative AI at Chime) using a coding agent (Cursor) as his PM system for PRDs, Jira tickets, status reports and prototypes. Host Claire Vo is ChatPRD's founder (a PM-tool vendor). The "20 minutes" anecdote is from Builder.io (sells a competing tool), not this episode. Evidence kind: anecdote. Re-check 2026-10-24: episode page and both Builder.io pages fetched and claims checked.

## Themes
- prd-agents: PRDs written in Cursor as source-controlled markdown, pushed to Confluence/Notion via MCP, Jira tickets generated from PRDs, status reports from Jira data (episode show notes) (case 20); Builder.io's Cursor piece adds that his PRDs reference the actual codebase
- non-engineer-builders: Builder.io (Claude Code for PMs, 2026-02-10): Dennis Yang turns a markdown PRD into a prototype with Claude Code, "Twenty minutes later, the PRD is a running prototype"
- org-context-grounding: Codebase grounding of PRDs (Builder.io Cursor piece); claim that prototypes are generic or disconnected from the real product (unverified: not found in either Builder.io page)
- docs-as-code-prd: PRDs kept as source-controlled markdown files in Cursor rather than in a SaaS doc tool (episode show notes; bullet originally filed by user-story-mapping)

## Key points
- Episode (2025-10-27, host Claire Vo): Cursor used as a no-code PM system: PRD creation, docs, Jira ticket creation, status reporting, replying to comments; MCPs to Confluence and Notion; Cursor as a "super MVP" environment for prototyping AI products. No "20 minutes" claim; Builder.io not mentioned.
- Extra URL https://www.builder.io/blog/cursor-for-product-managers (Vishwas Gopinath, 2026-02-23; promotes Builder.io): Yang drafts PRDs referencing the real codebase, publishes to Confluence/Notion via MCP, generates Jira tickets. Limitations listed: MCP reliability, learning curve, no persistent memory, solo tool with no shared context. Does not say prototypes are generic.
- Extra URL https://www.builder.io/blog/claude-code-for-product-managers (Vishwas Gopinath, 2026-02-10; heavy Builder.io promotion): the "twenty minutes" PRD-to-running-prototype anecdote, about Claude Code (not Cursor).
