## Relevance to the project
Launch post for Claude Design's design-system enforcement (import from GitHub, design files or uploads; Claude checks output against the system; an admin approves one standard and locks edits) and its sync with Claude Code, which together sketch a governed design-to-code handoff for the artifact-structure and intent-shaping dimensions. It also lists the export routes (PDF, PowerPoint, HTML, nine partner connectors) and enterprise defaults (off by default on Enterprise, links shared inside the org by default). It is a product announcement with partner quotes; the only number is a usage claim.

## Themes
- artifact-standardization: one or several design systems imported; Claude builds with components, checks output and corrects before you see it; admin role approves a standard system and locks edits ("Build with your design system components").
- enterprise-admin-controls: off by default on Enterprise; admins enable it for the whole org or specific groups (Organization settings > Artifacts); on Team and Enterprise, links are shared inside the organisation by default ("Getting started").
- spec-becomes-prototype-and-evals: `/design-sync` pulls the design system so designs start from real components; a design hands off to Claude Code, which continues from the work rather than a screenshot; code can be turned into a live prototype ("Move between design and code").
- harness-portability: export to PDF, PowerPoint, HTML and connectors to Adobe, Base44, Canva, Gamma, Lovable, Miro, Replit, Vercel, Wix ("From the canvas to the tools you use").

## Key points
- Anthropic states over one million people used Claude Design in its first week (no definition of "used").
- September 2026 update banner: Claude Design now works inside any conversation, including Claude Code and the Artifacts tab, in beta on paid plans; decks moved to Claude Slides.
- New editor with direct manipulation (drag, resize, align) and "hundreds of stability fixes"; usage limits now shared with the rest of Claude, including Claude Code.
- Partner quotes (Miro, Vercel, Canva, Replit, Lovable, Gamma, Wix, Adobe, Tenex/Morning Brew cofounder) are endorsements of integrations, not outcome evidence. Several quotes appear twice in the extract (carousel duplication).
- Missing: how design-system "checks" work or how often they catch violations; what a locked system prevents; audit of shared links.
