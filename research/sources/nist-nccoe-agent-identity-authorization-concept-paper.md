## Relevance to the project
NIST's NCCoE has opened a project to show how existing identity standards apply to AI agents, covering identification, authorisation, auditing, non-repudiation and prompt-injection controls. For regulated buyers this is the reference point their security teams will cite when asked "can an agent act for a product team?", and it signals that agent identity is treated as an extension of existing IAM rather than a new discipline.

## Themes
- identity-delegation: asks for feedback on use cases, agent-specific challenges, current and emerging standards and technologies for agent identity and access management (announcement).
- agent-protocol-security: detailed questions cover identification, authorisation, auditing and non-repudiation of agents plus controls for prompt injection (announcement).
- decision-rights-for-agents: the framing is agents acting autonomously "on data and tools", requiring identification and authorisation controls to manage access risk.

## Key points
- Comment period closed 2 April 2026; comments subject to FOIA release.
- Per search summaries of the PDF: candidate standards named include OAuth, OpenID Connect, SCIM, SPIFFE/SPIRE; NIST SP 800-207, SP 800-63-4 and NISTIR 8587 to be applied; RAG and LLM-only implementations out of scope.

## Notable quotes
- The NCCoE is "interested in launching a project to demonstrate how identity standards and best practices can be applied to software agents".
