## Relevance to the project
A vendor-contributed summary of Gartner's Market Guide for Guardian Agents (2026-02-25, limited distribution). Gartner's vocabulary differs from Forrester's: "guardian agents" supervise other agents. The summary says Gartner sees deployments as mostly pilots and argues for a neutral, platform-agnostic oversight layer rather than governance embedded in each platform. Treat as second-hand.

## Themes
- agent-control-plane: three capability areas (visibility and traceability; continuous assurance and evaluation; runtime inspection and enforcement); six delivery models (standalone oversight platforms, AI/MCP gateways, embedded runtime modules, orchestration-layer extensions, hybrid edge-cloud, coordination standards/APIs).
- vendor-claims-vs-independent-evidence: "guardian agent deployments are mainly prototypes or pilots" (Gartner, as quoted).
- identity-delegation: pair each agent with a human sponsor; time-bound least-privilege access.

## Key points
- Gartner abstract (2026-05-14, paywalled, seen only as search snippet) titled "Accelerate AI Agent Governance and Security Using Platform-Agnostic Guardian Agents".
- Related Gartner items seen only via secondary summaries: "agent washing" (June 2025, ~130 of thousands of agentic vendors "real"); first Hype Cycle for Agentic AI (2026) names agent washing as a hazard and recommends MCP plus an MCP gateway (per Tray.ai blog).
