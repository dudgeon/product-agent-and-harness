## Relevance to the project
A draft pull request that lets people draw on Omnigent's Canvas: frames, sticky notes and arrows bound to session cards. It shows the board moving from a session switcher toward a place for structure, which is the direction the canvas-coach concept film pushes much further. Here the drawing is done by the person, by hand; nothing is generated by an agent or built from a template.

## Themes
- [[product-artifact-primitives]]: a toolbar with Select, Draw, Frame, Note, Arrow and Delete; arrows that start or end on a session card, frame or note stay attached when it moves (Summary).

## Key points
- New release feature `canvas_whiteboard`, off by default, shown only where `canvas` is on.
- Drawings pan and zoom with the cards.
- The description says the request came from a user who wanted to "sketch their agent graph next to their sessions", and that the scope is a guess because no concrete use case was given.
