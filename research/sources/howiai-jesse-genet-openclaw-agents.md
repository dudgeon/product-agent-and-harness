## Relevance to the project
A non-engineer runs five OpenClaw agents, each with a role (homeschool, finance, scheduling, development, operations), its own SOUL.md persona file and its own Mac Mini, layered on an Obsidian "second brain". The project-relevant points are structural: role-scoped agents with data partitioned by machine, onboarding agents "like employees", "decision files" to make choices stick, and her report that agent-to-agent handoffs break because no messaging platform handles them well. That is a small data point on the persona-sub-agent shape the film's Helm concept uses and on its weak spot (handoffs). Household use and show notes only, so relevance is low.

## Themes
- one-job-per-agent: five specialised agents, "each one operates with clear scope and responsibility" (show notes intro; chapter 14:39).
- task-context-isolation: each agent deployed on its own Mac Mini, with data partitioned across machines (show notes; chapter 18:19 "Partitioning data across Mac Minis").
- memory-architecture: SOUL.md per agent for personality (chapter 13:09); "decision file" trick and memory management (chapter 44:00).
- agent-failure-modes: "Where multi-agent collaboration breaks down, and why no current messaging platform handles agent-to-agent handoffs well" (show notes "What you'll learn"; chapter 16:43).
- non-engineer-builders: a coding agent built a custom kids' TV app shipped to a real television in four days "with zero prior terminal experience" (show notes; chapter 27:00).

## Key points
- Curriculum workflow: photograph a curriculum book; an agent produces formatted lesson plans; a photographed inventory of toys, books and supplies lets the agent recommend physical materials (show notes; chapters 7:12, 37:00).
- Voice-to-print loop reduced from scan, upload, email, print to a spoken request in about 30 seconds (show notes; chapter 41:00).
- Tools named: OpenClaw, Obsidian, Slack, QuickBooks, Gemini, Mac Mini (show notes).
