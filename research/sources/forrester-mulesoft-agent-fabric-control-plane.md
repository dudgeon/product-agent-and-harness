## Relevance to the project
A public analyst argument that the cross-platform control layer is more strategic than any vendor's agent runtime, because build and orchestration converge while control must span many platforms (like API management). Supports keeping governance separable from whichever harness or agent we build or buy.

## Themes
- agent-control-plane: Forrester splits agentic AI into build, orchestration (runtime) and control (governance) layers; MuleSoft Agent Fabric is Salesforce's control plane (AI gateways, token cost analytics, portal of LLMs, MCP servers and agent cards, versioned LLM/MCP/A2A endpoints).
- build-vs-buy: warns Salesforce's stack is a patchwork of acquisitions with complex SKUs.
- harness-portability: control layer must span many platforms.

## Key points
- Agentforce sits in the less cohesive orchestration layer; risk Salesforce over-invests there while Agentforce and MuleSoft units stay siloed.
- Agent Fabric "has a strong lead compared to the competition" (analyst opinion).

## Notable quotes
- "Unlike the rest of the platform, Salesforce's AI agent control plane is already one holistic product: Agent Fabric."
- "Bolted-together Frankensteins create friction through unduly complex user experiences and complicated SKU purchases."
