## Relevance to the project
A PI planning template published by an agile coach at Humana, a large US health insurer, shows the artifact set a regulated enterprise uses to plan dependencies across several release trains at once: a multi-ART agenda across time zones, a Solution Board for cross-ART dependencies, team Program Boards, a ROAM risk board and a confidence vote. It illustrates that in large regulated orgs dependency planning has two tiers (between trains and between teams), each a separate board kept by hand.

## Themes
- dependency-types-and-practices: Solution Board "manages cross-ART dependencies" with a swimlane per ART listing capabilities and dependencies; Program Board shows team-level features and dependencies, where teams "add their features and dependencies and link to each other" (template description).
- process-artifacts-as-coordination: boards included are PI Calendar, multi-ART PI Planning Agenda, Solution Board, team areas, Program Board, Program Risk ROAM Board (resolved, owned, accepted, mitigated) and ART Confidence Vote (1-5).

## Key points
- Describes itself as "the ultimate PI Planning All In One template board for all your Scaled Agile Framework PI Planning Needs."
- An individual's community template, not a documented Humana process.
