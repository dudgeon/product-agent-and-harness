## Relevance to the project
CrewAI pairs Flows (state, control flow) with Crews (role-playing agent teams). It represents the role-based multi-agent framework style, which independent engineering voices (Cognition) warn against for coding work.

## Themes
- agent-frameworks: Flows for structure, Crews for autonomous collaboration; "use both".

## Key points
- Flows are the application backbone (state, events, conditional logic); Crews run inside Flow steps.
- Claims over 100,000 developers certified via community courses (vendor claim).
