## Relevance to the project
Concrete incident: of 2,857 skills on ClawHub, 341 were malicious, 335 from one campaign (ClawHavoc) using a fake "prerequisite" step to install the Atomic macOS stealer, with typosquatted names and lures such as crypto and Google Workspace tools. Shows the attack is social engineering through the instruction text, which no format-level sandbox prevents.
