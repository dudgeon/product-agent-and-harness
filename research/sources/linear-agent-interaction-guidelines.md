## Relevance to the project
Linear's published rules for how agents should behave inside a product-management tool. The decision-rights principle is unambiguous: agents can do work but "the final responsibility should always remain with a human", and an agent-delegated issue still names a responsible human. That is the clearest vendor statement of the accountability split a PM agent operating on tickets has to respect.

## Themes
- identity-delegation: agents must disclose they are agents (badge in user lists) and use the same standard actions a human user would.
- human-review-gates: "Agents can't be held accountable": humans keep final responsibility; delegated issues show a responsible human.
- agent-stewardship: respect requests to disengage: stop immediately and resume only on a clear signal.

## Key points
- Six principles: disclose agent status; work natively in the platform; give instant feedback ("Silence leads to uncertainty"); be transparent about internal state (thinking, waiting, executing, done; reasoning, tool calls and prompts inspectable); respect requests to disengage; agents can't be held accountable.
- Classification: these are interaction and decision-rights norms, not content standards; stance toward the human = defer on responsibility, inform on state.
- Does not cover when agents should ask for clarification.
