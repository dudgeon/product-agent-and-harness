## Relevance to the project
Controlled user study (47 participants, five security tasks in three languages): those with an AI assistant wrote significantly less secure code and were more confident it was secure. People who trusted the AI less and iterated more on prompts did better. It is evidence that confidence in reviewed AI output rises as quality falls, and that engaged scepticism is a trait to select for.

## Themes
- `overreliance-and-deskilling`: assistant users produced more vulnerabilities (notably string encryption and SQL injection) and rated their code more secure.

## Key points
- Small sample, an old model (codex-davinci-002), a security-specific task set; the effect for current agents is unmeasured. Sample size comes from search summary; abstract gives no numbers.
