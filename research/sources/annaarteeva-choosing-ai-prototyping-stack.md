## Relevance to the project
Design practitioner who teaches AI prototyping workshops moved Bolt to v0 to Lovable and prefers Lovable; a subjective "for me" comparison, not a benchmark. Not affiliated with any tool vendor (no sponsorship disclosed), but she sells a Maven course ("AI Prototyping for Designers") promoted in the post. Audit 2026-10-24: original fetched in full and claims checked.

## Themes
- prototyping-agents-limits: Practitioner migration Bolt -> v0 -> Lovable after "a bunch of small annoyances piled up"; Lovable is her default workshop tool, v0 second; notes Figma Make code-reuse problems and bugs (case 17)

## Key points
- Practitioner Anna Arteeva started workshops on Bolt, moved to v0, then switched to Lovable; prefers Lovable for all-in-one backend (Lovable Cloud/Supabase), two-way GitHub sync, built-in AI features.
- v0 ranked second (visual taste; locked to React/Tailwind/shadcn; one-way GitHub export). Bolt: rough UX, more bugs. Figma Make: precise Figma-to-prototype but code reuse problems and many bugs.
- Own testing as of late 2025; opinion, not measured.
