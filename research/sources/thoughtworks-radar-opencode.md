## Relevance to the project
The one well-known independent assessor that rates an open harness: Thoughtworks puts OpenCode in Assess (April 2026). Its reasons (model flexibility, self-hosted and air-gapped use, plugins and MCP for guardrails) are the regulated-setting reasons, with a warning to understand licensing and provider terms.

## Themes
- harness-portability: works with hosted frontier models, self-hosted endpoints and local models; suits cost control and restricted environments "including air-gapped setups".
- vendor-claims-vs-independent-evidence: Assess, not Trial or Adopt; no Thoughtworks blip found for Goose in the same Tools quadrant, and Cline's Trial blip (April 2025) has dropped off the current edition.

## Key points
- Ring: Assess, Vol. 34 (2026-04-15). "Terminal-first experience".
- Extension model (plugins, MCP) lets teams build their own workflows, tools and guardrails.
- Notes many users add "Oh My OpenCode", an opinionated package with coordinated agent teams.
- Users "must understand licensing and provider terms when using subscriptions or APIs" (an oblique reference to the Anthropic subscription dispute).
