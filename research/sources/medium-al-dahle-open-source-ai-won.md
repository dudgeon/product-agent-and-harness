## Relevance to the project
Airbnb's new CTO's thesis, written a month into the job: models, fine-tuning tools, orchestration and agent scaffolding are all commoditising, so durable advantage is proprietary data, deep workflow integration and above all "taste" in how AI meets a real person. Airbnb engineers cite it (airbnb-tech-insight-miner-agent-harness) as the reason harnesses matter. It frames the build-vs-buy logic behind AirChat and Everest and argues the "blinking cursor" empty chat box is a design failure.

## Themes
- build-vs-buy: "If your advantage depends on which model you're calling, you don't have an advantage. You have a temporary arrangement." Value moves to data, workflow integration and taste.
- harness-portability: the agent layer itself is being commoditised by open source (cites OpenClaw passing 150,000 GitHub stars by Feb 2026).
- product-coherence-over-automation: taste is "thousands of smaller decisions": when to ask a clarifying question, how much reasoning to show, one option or three, how to behave when not confident.

## Key points
- Claims the open-closed model gap "effectively vanished" across 2025 and early 2026 (author's view, citing DeepSeek and Qwen3).
- Durable advantages named: hardware, ecosystems with network effects, and taste.
- Organisational point: treating AI deployment as purely technical yields generic products; a culture of craft is what competitors cannot copy by switching models.
