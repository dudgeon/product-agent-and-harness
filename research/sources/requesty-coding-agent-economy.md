## Relevance to the project
One of the few cross-agent cost datasets: gateway telemetry on nine coding agents (May 2025 to April 2026) puts the mean active user at about $92/month, Claude Code at $108 mean but only $23 median and $291 at P95, with every agent showing a large mean-to-median gap. For always-on, shared agents the lesson is that spend is driven by a small tail of heavy, long-running usage, so cost control has to target the tail (runaway or always-on sessions), not the average seat. Vendor data (Requesty sells LLM routing) with selection bias; it does not isolate unattended or overnight runs.

## Key points
- "Active" = at least two active days in a month. Claude Code averaged 1,549 API calls per user per month by April 2026.
- The report says P95 users are "running extended agentic sessions daily" but does not analyse runaway or overnight behaviour.
- Absolute user counts and total spend are not reported.
