## Relevance to the project
A PM-audience restatement of Ramp's Glass, published four days after [Seb Goddijn's founding article](x-sebgoddijn-glass-article.md), which is its only source; it adds no new Ramp facts. What it adds is a translation of Glass into four portable principles (integrations auto-connected at the identity layer; a compounding skill marketplace with a recommender; memory built from connections before the first message; scheduled and headless automations posting to Slack) and worked applications for B2B SaaS PMs, fintech compliance and claims, and consumer city-ops. It also names the "internal AI specialist" as an emerging role. Downgraded from the triage guess of high because it is derivative of a source already filed in full; useful mainly as evidence of how Glass is being read by PMs, and for the SaaS-PM worked example.

## Themes
- skills-marketplace: Dojo described as markdown skills that are "executable, not just readable" and "versioned and reviewed like code"; Sensei recommends from role, connected tools and recent activity so a new PM "never has to browse 350 options". Matches [the Glass article](x-sebgoddijn-glass-article.md).
- org-learning-loop: the sales-rep battlecard skill published once and inherited by every rep; SaaS example of a senior PM's research-to-prioritised-spec skill reused by every PM.
- memory-architecture: memory profile built on first sign-in from every connected tool (tickets, channels, calendar, documents), so the agent has a working model of the user before the first message.
- enablement-by-product: auto-connected integrations framed as the answer to the biggest adoption barrier: "configuration already happened at the identity layer".
- build-vs-buy: relays Ramp's claim that internal productivity is a moat and that building internally informs the customer product; the author argues no one will replace the whole SaaS stack, but internal AI teams will connect it.
- pm-persona-role-expansion: "Internal AI specialist" roles at OpenAI, Figma, Replit and others (embedded job posts, second-hand).
- vendor-claims-vs-independent-evidence: 350+ skills and the adoption story are restated without data.

## Key points
- **Five capabilities (from Ramp):** auto-configured SSO and integrations; Dojo; Sensei; persistent memory; scheduled automations run from the user's laptop. Also headless tasks continued on mobile and Slack-native assistants that inherit the team's integrations, memory and skills.
- **Docs maintenance:** relays Ramp using headless automations to keep documentation current and flag issues in Slack (image embedded, not in text).
- **B2B SaaS PM application:** SSO auto-connect to Linear, Jira, Figma, Notion, Google Analytics; memory that knows the current sprint, blocked features, the last three customer calls and key stakeholders; a weekly product-health digest to the product channel before Monday standup.
- **Fintech/insurance:** compliance officer connected on install to warehouse, policy repositories, regulatory feeds and audit tools; an adjuster's claim-investigation workflow as a skill.
- **Consumer (DoorDash-style ops):** a city-launch workflow as a skill so each new market starts from the last; scheduled anomaly reports per city.
- **Framing:** relying wholly on third-party SaaS may come to look like "AI immaturity"; internal tools become an "AI excellence" flex.
