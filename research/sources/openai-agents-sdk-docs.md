## Relevance to the project
OpenAI's framework-style SDK: few primitives (agents, handoffs/agents-as-tools, guardrails, sessions, tracing, MCP, sandbox agents). A reference point for a lightweight, mostly provider-neutral SDK versus the coding-harness-in-a-box Claude Agent SDK.

## Key points
- Primitives: agents, handoffs/agents-as-tools, guardrails, function tools with schema generation, MCP tool calling, sessions, human-in-the-loop, tracing, sandbox agents, realtime/voice.
- Uses Responses API by default; non-OpenAI models via adapters (Any-LLM, LiteLLM); breadth of support not detailed on the page.
- Described as production-ready upgrade of Swarm.
- Separate announcement (April 2026, per search results only) added a model-native harness and native sandbox execution; not read first-hand.
