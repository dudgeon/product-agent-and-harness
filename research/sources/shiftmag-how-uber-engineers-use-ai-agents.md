## Relevance to the project
An independent-but-derivative report of the Pragmatic Summit talk by Anshu Chada and Ty Smith, plus figures from a CTO LinkedIn post; it never mentions Cortana, which supports dating Cortana after March 2026 in public material. Use the Summit talk note for claims; this adds only the CTO's post figures.

## Themes
- remote-agent-invocation: Minion takes a prompt via web, Slack or CLI and pings the engineer in Slack when the PR is ready.
- cost-control-routing: costs up at least 6x since 2024; model chosen per task.
- outcome-measurement-gap: Uber tracks activity, not business outcomes.
- leadership-permission-mandate: sharing wins beat mandates.

## Key points
- Added from the CTO's LinkedIn post (about a day after the talk, as relayed): 95% of engineers use AI monthly; 84% of AI users work agentically; Claude Code use 32% → 63% in two months; ~70% of committed code in IDE tools is AI-generated; the internal background agent writes 1,800 code changes a week, up from under 1% to 8% of all code changes in a few months.
