## harness-portability: Harness portability

## identity-delegation: Identity and delegation (on-behalf-of)
Who an agent acts as when one agent or harness calls another: user tokens, service accounts, delegation chains, revocation and audit. Cuts across remote agents, MCP/A2A and shared sessions.
- [MCP Authorization spec](sources/mcp-authorization-spec-draft.md): OAuth 2.1 resource-server model; servers must not accept or pass through tokens issued for other audiences; so on-behalf-of access downstream needs token exchange or a vault (first-party spec). (research-agent-runtime-patterns-taxonomy)
- [Cloudflare remote MCP](sources/cloudflare-remote-mcp-servers.md): the MCP server acts as OAuth provider to clients and OAuth client to GitHub/Google, issuing narrower tokens of its own (vendor). (research-agent-runtime-patterns-taxonomy)
- [Sentry MCP + Seer](sources/sentry-mcp-server-seer.md): OAuth consent with selectable permission sets for a vendor agent (vendor docs; partly unverified). (research-agent-runtime-patterns-taxonomy)
- [Copilot Studio A2A](sources/microsoft-copilot-studio-a2a.md): per-connection None/API key/OAuth; no user-identity propagation described. (research-agent-runtime-patterns-taxonomy)
- [Claude Code cloud sessions](sources/anthropic-claude-code-cloud-sessions.md): credentials kept outside the VM behind a proxy; auto-fix replies post under the user's GitHub account (vendor docs). (research-agent-runtime-patterns-taxonomy)
- [Ask HN A2A](sources/hn-ask-is-anyone-using-a2a.md): commenters: the open problems are who delegated authority, revocation and trusting claimed capability (anecdote). (research-agent-runtime-patterns-taxonomy)
- [Cloudflare OS announcement](sources/cloudflare-os-announcement.md): agents start with zero access; typed bindings; Gatekeepers hold credentials; shared agents reflect the viewer's permissions via an observation log (vendor claim) (research-agent-runtime-patterns-taxonomy)
- [Omnigent repo issue #11413](sources/github-omnigent-repo.md): session sharing did not separate chat access from host access to terminals and files (open P1 issue, 2026-10-23) (research-agent-runtime-patterns-taxonomy)

## work-structure-spectrum: Work structure spectrum (unstructured exploration to task-specific workflow)
