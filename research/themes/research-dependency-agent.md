## agent-legible-platform: The agent-legible platform
The kinds of information an agent needs about a platform (identity, ownership, contracts, intake, checks and approvers, lead times, calendar, decisions) and the most machine-readable form each has today; the intake rung is strongest, approvals and lead times weakest. Related: [[legible-org-for-agents]].
- [Agent READMEs: An Empirical Study of Context Files for Agentic Coding](sources/arxiv-chatlatanagulchai-agent-readmes.md): across 16 instruction types, most common are test procedures (75.9%), implementation details (70.8%), architecture (68.1%). (independent; research-dependency-agent)
- [MCP Actions (Backstage AI docs)](sources/backstage-docs-mcp-actions.md): "The MCP Actions Backend exposes Actions registered with the Actions Registry as MCP tools"; actions from configured `pluginSources` (e.g. `catalog`, `scaffolder`) appear as tools, splittable into several MCP endpoints with include/exclude rules. (first-party; research-dependency-agent)
- [Writing Templates (Backstage Software Templates)](sources/backstage-docs-writing-templates.md): catalog-aware fields (`OwnerPicker` filtered by `catalogFilter`, `RepoUrlPicker` limited by `allowedHosts`/`allowedOwners`) tie the intake to the ownership graph (Custom fields). (first-party; research-dependency-agent)
- [Open Data Contract Standard (ODCS)](sources/bitol-odcs-open-data-contract-standard.md): contract sections: Fundamentals, Schema, Data Quality, Support & Communication Channels, Pricing, Team, Roles, SLA, Infrastructures & Servers, Authoritative Definitions, Tags, Custom properties (index). (first-party; research-dependency-agent)
- [FedRAMP 20x](sources/fedramp-20x-overview.md): Key Security Indicators (KSIs) were the Phase 1 proof of concept for automated validation; Phase 2 found presenting requirements as KSIs "confusing". (first-party; research-dependency-agent)
- [FINOS Common Cloud Controls (CCC)](sources/finos-common-cloud-controls.md): technology-agnostic Core Catalog of threats and controls that organisations import and extend with service-specific catalogs. (first-party; research-dependency-agent)
- [About code owners](sources/github-docs-about-code-owners.md): gitignore-style patterns, last match wins; file in `.github/`, root or `docs/` of the base branch. (first-party; research-dependency-agent)
- [Dev Portal MCP server (Kong Konnect)](sources/kong-docs-dev-portal-mcp-server.md): read tools: `list_apis`, `fetch_api_spec(_raw)`, `list_api_documents`, `get_portal_form`, `list_application_auth_strategies` and others (Tools). (first-party; research-dependency-agent)
- [Promises (Kratix reference)](sources/kratix-docs-promises-intro.md): the request API is a namespace-scoped CRD; `requiredPromises` declares dependencies between platform offerings (API, Requirements). (first-party; research-dependency-agent)
- [The /llms.txt file](sources/llmstxt-org-llms-txt-proposal.md): fixed Markdown structure: required H1 name, optional blockquote summary, optional prose, H2 sections of link lists; an "Optional" H2 marks links an agent may skip for shorter context (Format section). (first-party; research-dependency-agent)

(first-party; research-dependency-agent)
- [OSCAL: the Open Security Controls Assessment Language (layers and models)](sources/nist-oscal-layers-and-models.md): a Component Definition describes how a component (e.g. a platform service) implements controls, which a consumer can inherit; formats XML, JSON, YAML (OSCAL home). (first-party; research-dependency-agent)
- [Port MCP server: overview and installation](sources/port-docs-remote-mcp-server.md): blueprint, entity and scorecard tools expose the catalog and its standards to agents. (first-party; research-dependency-agent)
- [50% of engineers lack trust in the data they rely on most](sources/port-state-of-idp-2025-metadata-trust.md): 25% of orgs still use a CMDB and 17% spreadsheets as metadata store; 53% have implemented an internal developer portal, 23% specifically as metadata repository. - [Spectral: a flexible JSON/YAML linter for creating automated style guides](sources/stoplight-spectral-readme.md): example public rulesets from Adidas, Azure and Zalando show large orgs publishing their API style rules as code. (first-party; research-dependency-agent)

## cognitive-load-and-platforms: Cognitive load and platforms
Team Topologies' framing: platforms exist to reduce stream-aligned teams' cognitive load, and badly built platforms add to it.
- [Atlassian research: AI adoption is rising, but friction persists (State of Developer Experience 2025)](sources/atlassian-state-of-devex-2025.md): adapting to new technology and context switching between tools are the next two time-wasters. (vendor-claim; research-dependency-agent)
- [CNCF Platforms White Paper](sources/cncf-tag-app-delivery-platforms-white-paper.md): the first stated purpose of platforms is to reduce cognitive load on product teams (Why platforms). (independent; research-dependency-agent)
- [Capabilities: Platform engineering](sources/dora-capability-platform-engineering.md): platform engineers should "shift down" complexity into the platform rather than expecting developers to become experts in it (Cognitive load section). (independent; research-dependency-agent)
- [2025 State of Internal Developer Portals](sources/port-state-of-internal-developer-portals-2025.md): 75% lose 6-15 hours weekly to tool sprawl; average 7.4 tools for everyday operational tasks. (vendor-claim; research-dependency-agent)
- [Platform as a Product in a 300-Year-Old Bank](sources/syntasso-natwest-platform-as-product-300-year-old-bank.md): high cognitive load on developers and duplicated effort across teams named as the starting problem. (vendor-claim; research-dependency-agent)
- [Google DORA issues platform engineering caveats](sources/techtarget-pariseau-dora-2024-platform-engineering-caveats.md): the report's caveat that the gains "do not come without some drawbacks". (independent; research-dependency-agent)
- [A decade of cloud native at ING: lessons learned and what comes next](sources/techzine-nardiello-ing-decade-cloud-native.md): "Suddenly, thirty solid interfaces feel like thirty different products." (first-party; research-dependency-agent)

## coordination-cost-and-waiting: Coordination cost: elapsed time is waiting on other parties
Evidence on how much elapsed time in cross-team work is waiting, chasing and finding rather than working; it matters because this is the cost a dependency agent is meant to cut and the number nobody publishes.
- [Dependency Management in Large-Scale Agile: A Case Study of DevOps Teams](sources/aisel-stray-moe-aasheim-dependency-management-devops-teams.md): dependencies between and within teams must be managed at both project and team levels in large-scale agile (Abstract). (independent; research-dependency-agent)
- [The difficulties of cascading OKRs](sources/allankelly-difficulties-cascading-okrs.md): each level waits for the level above, and setting OKRs takes reflection and iteration, so three layers can take a week or more: "you have a delay built into the system". (anecdote; research-dependency-agent)
- [Automating Low-Risk Code Review at Meta: RADAR, Risk Calibration, and Review Efficiency](sources/arxiv-adams-meta-radar-low-risk-review.md): median time to close down "by over 330%" (the paper's phrasing) and median review wall time down 35%; lines per landed diff +105.9% YoY and per-developer diff volume +51%. (first-party; research-dependency-agent)
- [Coordinating Knowledge Work in Multi-Team Programs: Findings from a Large-Scale Agile Development Program](sources/arxiv-dingsoyr-coordinating-multi-team-programs.md): "In the business project, much of the work concentrated on managing dependencies, 'there were dependencies throughout the program'" (§Group mode); separate meetings were held "to identify dependencies in tasks before work was assigned to teams". (independent; research-dependency-agent)
- [Nudge: Accelerating Overdue Pull Requests Towards Completion](sources/arxiv-maddila-nudge-overdue-pull-requests.md): 60% reduction in PR resolution time in the randomised trial. (first-party; research-dependency-agent)
- [Challenges of Adopting SAFe in the Banking Industry – A Study Two Years after its Introduction](sources/arxiv-tengstrand-safe-banking-challenges.md): related-work summary (§3.1) reports that an American bank found "it was difficult for teams to deliver independently because of dependencies outside of the teams"; Nordea's teams in one ART were frustrated because "delivery streams were not in unison", with PI planning reported as the unifying fix. (independent; research-dependency-agent)
- [Identifying Critical Dependencies in Large-Scale Continuous Software Engineering](sources/arxiv-tkalich-critical-dependencies-cse.md): the framing is delay and bottleneck, not effort: the cost of a dependency is waiting time at a function outside the team. (independent; research-dependency-agent)
- [Atlassian research: AI adoption is rising, but friction persists (State of Developer Experience 2025)](sources/atlassian-state-of-devex-2025.md): 50% of developers lose 10+ hours a week to organisational inefficiencies; 90% lose 6+ hours (blog body). Evidence: vendor survey. (vendor-claim; research-dependency-agent)
- [Black Swan Farming using Cost of Delay](sources/blackswanfarming-maersk-cost-of-delay.md): 82 hours of develop-and-test in 46 weeks end to end, "over 38 weeks" of waiting, 29 weeks in the fuzzy front end (value stream map). By calculation (not in the paper) active time is roughly 4% of elapsed time. (vendor-claim; research-dependency-agent)
- [Coordination Breakdowns and Their Impact on Development Productivity and Software Failures](sources/cataldo-herbsleb-coordination-breakdowns.md): "higher levels of congruence are associated with improved development productivity" (Abstract), measured as resolution time of modification requests (section 7). (independent; research-dependency-agent)
- [DORA Report 2024 (Accelerate State of DevOps)](sources/dora-accelerate-state-of-devops-2024.md): platforms can decrease throughput and change stability (findings list); see techtarget-pariseau-dora-2024-platform-engineering-caveats for the figures (-8% throughput, -14% stability). (independent; research-dependency-agent)
- [Capabilities: Platform engineering](sources/dora-capability-platform-engineering.md): 2024 finding that developer independence, the ability to complete tasks without relying on an enabling team, was linked to a 5% productivity improvement at team and individual levels (Key findings). (independent; research-dependency-agent)
- [Capabilities: Streamlining change approval](sources/dora-capability-streamlining-change-approval.md): suggested metrics include "time changes spend waiting for external or local approval" and the proportion of changes requiring external approval by risk profile (Measuring). ## dependency-detection-automation: Automatic dependency detection: what research and vendors can do
Accuracy of link-type prediction in issue trackers, requirement-dependency extraction with language models, and what shipped planning agents actually do with dependencies (read declared ones, alert, propose re-plans).
- [A Taxonomy of Dependencies in Agile Software Development](sources/aisel-strode-huff-dependency-taxonomy-agile.md): the taxonomy is a classification target an agent could label asks against; the paper itself is qualitative. (independent; research-dependency-agent)
- [Automating the Detection of Requirement Dependencies Using Large Language Models](sources/arxiv-darif-leredd-requirement-dependencies.md): zero-shot GPT-5.4 overall F1 0.78, but only 0.29 average F1 on specific dependency types; LEREDD with six retrieved examples per type reaches Requires F1 0.86 in the pilot, about 86% F1 and 87% accuracy overall, with only a 2.27% drop when moved to a new system (RQ1-RQ5). (independent; research-dependency-agent)
